User stories, grouped into epics. Each story follows [`user-story-template.md`](./user-story-template.md) and links back to the requirements in [`../01-prd.md`](../01-prd.md).

## Status values

`Draft` · `Ready` · `In progress` · `Built` · `Verified`

## Conventions

- A story is not done until its acceptance criteria hold *and* affected docs are updated in the same change (see [`../../RULES.md`](../../RULES.md)).
- Stories that depend on unresearched law are blocked until the research exists — never fill the gap with a guess.
